# Rinvio Privacy Policy / プライバシーポリシー

Effective date / 発効日: August 12, 2026

## English

Rinvio does not collect, store, sell, or transmit personal data, keyboard input, telemetry, or analytics.

### Keyboard input

Rinvio uses macOS Input Monitoring only to compare keyboard events with shortcuts configured in the app. It does not record typed text or retain a history of keyboard events. When a configured Trigger matches an enabled target, Rinvio uses the macOS Post Event permission to send the target application's official keyboard shortcut. If Rinvio cannot safely route or deliver an Action, it leaves the original keyboard event available to the foreground application.

### Browser context

When Google Chrome is in the foreground, Rinvio may ask Chrome for the active tab URL through Apple Events to identify supported web applications, show the Shortcut Guide, or open settings for the last-used application. The URL is evaluated locally to match only its scheme and host. Rinvio does not save or transmit the full URL, path, query, fragment, tab title, meeting code, or message content.

### Local settings

Custom shortcuts, cleared shortcuts, application enablement, language, and display preferences are stored locally on the Mac. Rinvio does not operate an account service or synchronize these settings to a server.

### Third parties

Rinvio does not include third-party advertising, analytics, or tracking SDKs. Names of supported applications identify compatibility only and do not imply endorsement or affiliation.

### Changes and contact

Material changes to this policy will be published on the [Rinvio website](https://keishingu.github.io/Rinvio/privacy.html) and in this repository. For privacy questions or support, see the [support page](https://keishingu.github.io/Rinvio/support.html) or open an issue at <https://github.com/keishingu/Rinvio/issues>.

## 日本語

Rinvioは、個人データ、キー入力、テレメトリ、解析データを収集、保存、販売、送信しません。

### キー入力

Rinvioは、キーボードイベントがアプリ内で設定されたショートカットと一致するかを確認するためだけに、macOSの「入力監視」を使用します。入力された文章を記録せず、キーボードイベントの履歴も保持しません。設定済みのTriggerが有効なTargetと一致した場合、macOSのPost Event権限を使い、対象アプリの公式キーボードショートカットを送信します。Actionを安全にルーティングまたは配送できない場合、元のキーボードイベントをForegroundアプリで利用できる状態に保ちます。

### Browser Context

Google ChromeがForegroundの場合、Rinvioは対応Web Applicationの判定、Shortcut Guideの表示、最後に使ったApplicationの設定を開くために、Apple Eventsを通じてChromeへアクティブタブのURLを問い合わせることがあります。URLはschemeとhostの一致だけを端末内で判定します。完全なURL、path、query、fragment、タブタイトル、会議コード、メッセージ内容を保存・送信しません。

### ローカル設定

Custom Shortcut、Clear済みShortcut、Application Enablement、言語、表示設定はMac内に保存されます。Rinvioはアカウントサービスを提供せず、これらの設定をサーバーへ同期しません。

### 第三者

Rinvioは第三者の広告、解析、Tracking SDKを含みません。対応アプリ名は互換性を識別するためのもので、提携や推奨を示すものではありません。

### 変更と問い合わせ

本ポリシーの重要な変更は[Rinvio公式サイト](https://keishingu.github.io/Rinvio/privacy.html)とこのリポジトリで公開します。プライバシーに関する質問やサポートは、[サポートページ](https://keishingu.github.io/Rinvio/support.html)を確認するか、<https://github.com/keishingu/Rinvio/issues>でIssueを作成してください。
