# QuickDraw Shortcuts Privacy Policy / プライバシーポリシー

Effective date / 発効日: August 12, 2026

## English

QuickDraw Shortcuts does not collect, store, sell, or transmit personal data, keyboard input, telemetry, or analytics.

### Keyboard input

QuickDraw uses macOS Input Monitoring only to compare keyboard events with shortcuts configured in the app. It does not record typed text or retain a history of keyboard events. When a configured Trigger matches an enabled target, QuickDraw uses the macOS Post Event permission to send the target application's official keyboard shortcut. If QuickDraw cannot safely route or deliver an Action, it leaves the original keyboard event available to the foreground application.

### Browser context

When Google Meet or Gmail support is enabled in Google Chrome, QuickDraw asks Chrome for the active tab URL through Apple Events. The URL is evaluated locally to match only its scheme and host. QuickDraw does not save or transmit the full URL, path, query, fragment, tab title, meeting code, or message content.

### Local settings

Custom shortcuts, cleared shortcuts, application enablement, language, and display preferences are stored locally on the Mac. QuickDraw does not operate an account service or synchronize these settings to a server.

### Third parties

QuickDraw does not include third-party advertising, analytics, or tracking SDKs. Names of supported applications identify compatibility only and do not imply endorsement or affiliation.

### Changes and contact

Material changes to this policy will be published in this repository. For privacy questions or support, open an issue at <https://github.com/keishingu/QuickDraw/issues>.

## 日本語

QuickDraw Shortcutsは、個人データ、キー入力、テレメトリ、解析データを収集、保存、販売、送信しません。

### キー入力

QuickDrawは、キーボードイベントがアプリ内で設定されたショートカットと一致するかを確認するためだけに、macOSの「入力監視」を使用します。入力された文章を記録せず、キーボードイベントの履歴も保持しません。設定済みのTriggerが有効なTargetと一致した場合、macOSのPost Event権限を使い、対象アプリの公式キーボードショートカットを送信します。Actionを安全にルーティングまたは配送できない場合、元のキーボードイベントをForegroundアプリで利用できる状態に保ちます。

### Browser Context

Google ChromeでGoogle MeetまたはGmail対応を有効にした場合、QuickDrawはApple Eventsを通じてChromeへアクティブタブのURLを問い合わせます。URLはschemeとhostの一致だけを端末内で判定します。完全なURL、path、query、fragment、タブタイトル、会議コード、メッセージ内容を保存・送信しません。

### ローカル設定

Custom Shortcut、Clear済みShortcut、Application Enablement、言語、表示設定はMac内に保存されます。QuickDrawはアカウントサービスを提供せず、これらの設定をサーバーへ同期しません。

### 第三者

QuickDrawは第三者の広告、解析、Tracking SDKを含みません。対応アプリ名は互換性を識別するためのもので、提携や推奨を示すものではありません。

### 変更と問い合わせ

本ポリシーの重要な変更はこのリポジトリで公開します。プライバシーに関する質問やサポートは、<https://github.com/keishingu/QuickDraw/issues>でIssueを作成してください。
