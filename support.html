Rinvio Support

インストール、権限、更新、問題の切り分けを案内します。Rinvioは現在無料で配布しています。

日本語English

日本語

動作環境

  • macOS 15以降
  • Apple silicon／Intel Mac
  • Input MonitoringとAccessibilityの明示的な許可

インストール

  1. 最新版のDMGをダウンロードします。
  2. DMGを開き、RinvioをApplicationsへドラッグします。
  3. ApplicationsからRinvioを起動します。
  4. RinvioのInformation画面からInput MonitoringとShortcut Deliveryを順に許可します。

Triggerが反応しない場合

  1. RinvioのInformation画面でInput MonitoringとShortcut Deliveryが許可済みか確認します。
  2. System SettingsでRinvioがONになっていることを確認し、Rinvioを終了して起動し直します。
  3. Applications画面でForegroundアプリがRinvioの対象になっていることを確認します。
  4. Developer ModeのDry RunがONの場合は、検証後にOFFへ戻します。

権限が未許可、対象外Application、対応Mappingなしの場合、RinvioはTriggerを消費せず元のキー入力をForegroundアプリへ渡します。

権限を取り消す

System Settings → Privacy & Securityで、Input MonitoringとAccessibilityのRinvioをOFFにします。Input Monitoringを取り消すとTriggerを登録・消費しません。Accessibilityを取り消すとShortcutを配送できず、検出したTriggerは元のキー入力としてForegroundアプリへ渡します。

更新

最新版のDMGをダウンロードし、Applications内のRinvioを置き換えてください。設定は~/Library/Application Support/Rinvio/に保持されます。現時点では自動更新を行いません。

問い合わせ

不具合や対応Applicationの要望はGitHub Issuesへお寄せください。Information画面のDeveloper ToolsにあるCopy Diagnosticsは、キー入力や完全なURLを含まない直近のルーティング情報だけをコピーします。

English

Requirements

  • macOS 15 or later
  • Apple silicon or Intel Mac
  • Explicit Input Monitoring and Accessibility permission

Install

  1. Download the latest DMG.
  2. Open it and drag Rinvio into Applications.
  3. Launch Rinvio from Applications.
  4. Use Rinvio’s Information screen to allow Input Monitoring and Shortcut Delivery in order.

If a trigger does not respond

  1. Confirm that Information shows Input Monitoring and Shortcut Delivery as allowed.
  2. Confirm that Rinvio is enabled in System Settings, then quit and reopen Rinvio.
  3. Confirm that the foreground app is enabled under Applications.
  4. If Developer Mode’s Dry Run is on, turn it off after testing.

When permission is missing, an app is excluded, or no mapping is available, Rinvio does not consume the trigger and leaves the original key available to the foreground app.

Revoke permissions

In System Settings → Privacy & Security, turn Rinvio off under Input Monitoring and Accessibility. Revoking Input Monitoring stops Rinvio from registering or consuming triggers. Revoking Accessibility prevents shortcut delivery, and detected triggers pass through to the foreground app as their original keys.

Update

Download the latest DMG and replace Rinvio in Applications. Settings remain in ~/Library/Application Support/Rinvio/. Automatic updates are not available yet.

Contact

Report bugs or request app support through GitHub Issues. Copy Diagnostics under Information → Developer Tools includes only recent routing details and excludes keystrokes and full URLs.
